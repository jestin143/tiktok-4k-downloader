Para Permanent sa Lahat ng Visitors (Vercel)

Dahil Vercel ay serverless, yung Save mo ay localStorage lang (ikaw lang makakakita). Para makita ng LAHAT, gawin mo to:
  1. Click "Generate Export Code" sa baba
  2. Copy mo yung code
  3. Punta ka sa folder ng project mo, buksan mo config.json
  4. Paste mo yung ads code dun
  5. Re-upload / Re-deploy sa Vercel
  6. OR: Punta Vercel Dashboard → Settings → Environment Variables para sa login
